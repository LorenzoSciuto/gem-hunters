# CLAUDE.md

"Gem Hunters: Tag & Trap" by Wennovate: a 1–4 player (with optional bots) local split-screen 3D party game in **Godot 4.7** (GDScript, Forward Plus), for kids 9+.

The rules and the architecture are in @CONTRIBUTING.md. Follow them on every change and update that file when the structure changes. The player-facing overview is in README.md.

## Local notes

- The Godot binary is at `.tools/Godot_v4.7.2-stable_linux.x86_64` (git-ignored, too big for GitHub). Use it for the headless import check and for `-s` test scripts.
- Use "Wennovate" wherever a company, author or package name is needed. Never use a personal name.
- Work on feature branches with pull requests. Don't push to master directly.
